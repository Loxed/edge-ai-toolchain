# Notebook Workflow

We're using Marimo to manage our notebooks. Marimo is a tool that allows you to create and manage Jupyter notebooks in a more organized way. It helps you keep track of your notebooks, their dependencies, and their execution order.

Marimo notebooks are stored in the `__marimo__` directory and are defined as `.py` files with special comments that indicate the notebook structure. You can run these notebooks using the Marimo CLI, which will execute the code in the correct order and generate the corresponding `.ipynb` files.
